How Huffman coding works

A greedy algorithm that converts symbol frequencies into a compact, prefix-free binary code.

On this page

01 · The problem

Fixed-width codes ignore frequency

If four symbols are possible, a fixed-width representation needs two bits per symbol. But when A occurs far more often than D, treating them equally wastes bits. Huffman coding gives frequent symbols short codes and rare symbols longer ones.

Goal: minimize the weighted path length Σ frequency(symbol) × code_length(symbol) while keeping the code unambiguous.

02 · The algorithm

Always merge the two smallest

  1. Count the frequency of every distinct symbol.
  2. Create one leaf node for each symbol and place all leaves in a min-heap.
  3. Remove the two nodes with the smallest frequencies.
  4. Make them children of a new node whose frequency is their sum.
  5. Push the parent back into the heap and repeat until one node remains.
  6. Label left edges 0 and right edges 1.
while heap has more than one node:
    left  = remove_min(heap)
    right = remove_min(heap)
    parent = Node(left.freq + right.freq)
    parent.left, parent.right = left, right
    insert(heap, parent)

root = the only node remaining

This is a greedy choice: at every step, it commits to placing the two least frequent subtrees deepest together. Huffman's exchange argument proves that an optimal prefix tree exists with those two symbols as siblings.

03 · Worked example

AAAAAABBBCCD

SymbolFrequencyOne valid codeCost

The encoded payload costs 21 bits. A simple two-bit code for the same 12 symbols costs 24 bits. The exact codes can swap when frequencies tie, but their total cost remains optimal.

Real file compression must also store enough information to reconstruct the code tree, and it packs bits into bytes. A displayed string of “0” and “1” characters is a teaching representation, not the final binary file format.

04 · Decoding

Why no separator is needed

No Huffman code is the prefix of another. If A = 1, no other symbol can begin with 1. The decoder starts at the root, moves left for 0 and right for 1, emits a character upon reaching a leaf, and returns to the root.

for bit in encoded_bits:
    current = current.left if bit == "0" else current.right
    if current is a leaf:
        output current.symbol
        current = root

05 · Analysis

Time and space complexity

Let n be the text length and k the number of unique symbols.

OperationComplexity
Count frequenciesO(n)
Build the heap/treeO(k log k)
Generate codesO(k)
Encode / decodeO(n)
Tree + code map spaceO(k)

06 · Perspective

Optimal does not mean universal

Huffman coding is optimal among symbol-by-symbol prefix codes when the frequencies are known. It may perform poorly on tiny inputs once tree metadata is included, and it cannot assign fractional-bit lengths. Modern compressors often combine dictionary or context modeling with entropy coders such as arithmetic or range coding.
